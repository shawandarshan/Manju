## 🛠️ Tech Stack & Architecture

- **Semantic HTML5 & Vanilla JavaScript** — Ultra-lightweight, zero framework overhead, instant load speeds.
- **Custom CSS Design System** — Tailored HSL dark palette, smooth cubic-bezier transitions, fluid typography (`clamp()`), and responsive CSS grid.

- **Accessible & Responsive** — Supports screen readers, keyboard navigation, safe-area insets, and `prefers-reduced-motion` compliance.

## ⚡ Quick Start / Local Preview

You can run this project locally without installing any dependencies:

### Option 1: Direct Browser
Simply double-click `index.html` or `portfolio.html` in your file explorer, or open it in any modern browser.

### Option 2: Local HTTP Server
Using Python:
```bash
python3 -m http.server 3000
```
Then navigate to `http://localhost:3000` in your browser.

---

## 🌐 Deployment to GitHub Pages

1. Go to repository **Settings** on GitHub.
2. Under **Code and automation**, select **Pages**.
3. Under **Branch**, select `main` branch and `/ (root)` folder.
4. Click **Save**. Your site will be live at:
   ```
   https://shawandarshan.github.io/Manju/
   ```
